# Poisoning & Drug Overdose Assistant
Next.js 14 + TypeScript + Tailwind. Content from Harrison's Ch.459 (Tables 459-1 to 459-4).
Tabs: Assess (symptoms to toxidrome, tests, treatment), Pathophysiology, Treatment, Search, Updates.
## Deploy
git init && git add . && git commit -m "init" && git branch -M main
git remote add origin https://github.com/shivesh2334-ai/poisoning-overdose-app.git && git push -u origin main
Then import the repo in Vercel (framework: Next.js, region bom1 via vercel.json).
